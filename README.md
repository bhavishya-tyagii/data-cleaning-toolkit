## 🌌 About the Project

Data Cleaning Toolkit is a Python project that helps identify common data quality problems in tabular datasets.

## ✨ Planned Features

- Detect missing values.
- Identify duplicate rows.
- Display dataset dimensions and column names.
- Show basic numerical summaries.
- Export a cleaned dataset.

## 🛠️ Tech Stack

- Python
- Pandas

## 🎯 Learning Goals

- Understand data quality.
- Practice Python and Pandas.
- Learn practical data preprocessing.

## 🚧 Project Status

Currently in development. Features will be implemented and tested as the project grows.
